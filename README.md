
# VANTERA

**Everything you build. One platform.**

VANTERA is an all-in-one cloud platform for creating, deploying, hosting and managing digital projects.

## Features

- Bot hosting and development
- Website and application hosting
- Visual bot builder
- Template marketplace
- Cloud databases
- Deployment management
- File manager
- Live console and diagnostics
- Resource monitoring
- Subscription management
- Secure environment variables

## Technology

- Next.js
- React
- TypeScript
- PostgreSQL
- Docker

## Development

VANTERA is currently under development.
